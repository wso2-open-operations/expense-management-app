# expense-management-app

The EMA (expense_management) is a centralised solution to overview stats and access the related expense submission portals (E.g. Expense Claims, CC Expense Submissions, OPD Claims, etc.).

bal run
Terminal 2 — after Terminal 1 is running:


cd /Users/siddiha/Desktop/EMA/expense-management-app/backend
bal run
Terminal 3 — after Terminal 2 is running:


cd /Users/siddiha/Desktop/EMA/expense-management-app/webapp
npm install
npm run dev
